# Анализ продаж пиццы | SQL & Tableau

## О проекте
Комплексный аналитический проект на основе данных о продажах пиццерии за 2015 год. Цель - изучить динамику продаж, выявить наиболее востребованные продукты и определить закономерности в поведении заказов.
В проекте использованы **PostgreSQL для анализа данных и Tableau для визуализации результатов**.

## Данные
В анализе использованы 4 связанные таблицы:
- `orders` - информация о заказах;
- `order_details` - состав заказов и количество пицц;
- `pizzas` - размеры и цены;
- `pizza_types` - названия, категории и состав пицц.

**Объём данных:** 21 350 заказов, 49 574 проданные пиццы.

## SQL-анализ (PostgreSQL)

- Объединение таблиц с помощью `JOIN`.
- Расчёт ключевых метрик: выручки, количества заказов, проданных пицц и среднего чека.
- Анализ продаж по месяцам, дням недели и часам.
- Сравнение категорий, размеров и отдельных видов пиццы.
- Определение наиболее популярных продуктов по выручке и количеству продаж.

## Визуализация (Tableau)

Созданы три интерактивных дашборда:

**1. Business Overview**
- Ключевые показатели бизнеса.
- Динамика выручки по месяцам.
- Сравнение выручки по категориям и размерам.

**2. Order Patterns**
- Распределение заказов по дням недели и часам.
- Среднее количество пицц в одном заказе.

**3. Product Performance**
- ТОП-10 пицц по выручке и количеству продаж.
- Сравнение популярности продуктов и выручки.

Дашборды поддерживают фильтрацию по датам, категориям и размерам пиццы.

## Основные результаты

- Общая выручка составила **$817 860,05**, средний чек - **$38,31**.
- Наибольшая месячная выручка - в июле (**$72 557,90**).
- Пятница - самый загруженный день (**3 538 заказов**).
- Пиковое время заказов - 12:00–13:00.
- Категория Classic принесла наибольшую выручку - **$220 053,10**.
- Размер L лидирует по выручке - **$375 318,70**.
- Самая прибыльная по выручке пицца - Thai Chicken (**$43 434,25**).

## Используемые технологии

- **SQL / PostgreSQL** - обработка, объединение и анализ данных.
- **Tableau** - создание интерактивных дашбордов и визуализация результатов.
